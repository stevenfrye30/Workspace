Blueprints

A blueprint is anything you could make or do: a meal, a build, a repair. It lists what it consumes (needs) and what it uses without consuming (tools). Write butter|oil for "either one works" and ~parsley for "nice to have, not required".

Sync with GitHub

Your inventory lives as one JSON file in a private repo, so it's reachable from any phone and two people can work on it. Every change is a commit, so nothing is ever really lost.

1. Create a private repo — nothing in it, no README. github.com/new

2. Make a fine-grained token with Contents: Read and write on only that repo. create one

3. Paste it below. It's kept in this browser and nowhere else — it is never committed and never leaves your device except to talk to GitHub.

4. To share: add your partner on the repo under Settings → Collaborators. They make their own token and do this same setup.

Stays signed in after this — unless you're in Private Browsing, which forgets everything on close. Use a normal tab, and Add to Home Screen so it opens as its own app.
